## Não transportar entre plataformas

**CONFIRMED:** OMAP5 define base física SGX `0x56000000`, tamanho `0xffff`, IRQ 53 com comentário sobre offset 32; o caminho platform-resource pode fornecer os valores efetivos. Esses números não são offsets SGX genéricos. [references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.h:64-67](../references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.h#L64); [references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.c:199-226](../references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.c#L199).

**CONFIRMED:** Poulsbo mapeia recurso PCI 0 + `0x40000`, tamanho `0x8000`. Não copiar a janela OMAP, nem usar o offset MRST (`0x80000`) para Poulsbo. [references/linux/drivers/gpu/drm/gma500/psb_drv.h:41-53](../references/linux/drivers/gpu/drm/gma500/psb_drv.h#L41); [references/linux/drivers/gpu/drm/gma500/psb_device.c:272](../references/linux/drivers/gpu/drm/gma500/psb_device.c#L272); [references/linux/drivers/gpu/drm/gma500/psb_drv.c:261-262](../references/linux/drivers/gpu/drm/gma500/psb_drv.c#L261).

**CONFIRMED:** BRNs do ramo SGX535: revisão 121 ativa 22934/23944/23410; 126 ativa 22934; HEAD=0 não aplica BRNs nesse bloco. 23944 afeta tratamento de fault antes de reset BIF; 23410 força contexto TA válido. [references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/hwdefs/sgxerrata.h:134-159](../references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/hwdefs/sgxerrata.h#L134); [references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c:173-176](../references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c#L173); [references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c:471-495](../references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c#L471). **UNKNOWN:** mapeamento do stepping Intel para essa seleção de revisão.

**INFERRED:** abstrações de objetos, contexto, CCB, dependências e protocolo microkernel são úteis como modelo de investigação. Isso não implica ABI, scripts, cache policy, clocks, IRQs ou firmware binário portáveis. A divergência de indexação BIF em [mmu-bif.md](mmu-bif.md) é um exemplo concreto do risco.
