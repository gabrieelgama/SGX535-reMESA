# Generic SGX535, TI/OMAP and Intel Poulsbo

> Phase 2 update: local history contains `sgx535defs.h` and an explicit Poulsbo integration in DDK 1.14. The absence references below describe the Phase 1 master checkout. See [archaeology](source-archaeology.md), [recovered files](sgx535-missing-files.md), and [Poulsbo comparison](poulsbo-evidence.md) for the expanded state.

The comparison is between **SGX535 branch in shared code**, **actual TI OMAP4/5 integrations from this package**, and **Linux code for Poulsbo**. There is no evidence here of “SGX535 on OMAP” as a complete compilable target. ## Do not transport between platforms

**CONFIRMED:** OMAP5 defines SGX `0x56000000` physical base, size `0xffff`, IRQ 53 with a comment about offset 32; the platform-resource path can provide the actual values. These numbers are not generic SGX offsets. [references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.h:64-67](../references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.h#L64); [references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.c:199-226](../references/omap5-sgx-ddk-linux/eurasia_km/services4/system/omap5/sysconfig.c#L199).

**CONFIRMED:** Poulsbo maps PCI resource 0 + `0x40000`, size `0x8000`. Do not copy the OMAP window, nor use the MRST offset (`0x80000`) for Poulsbo. [references/linux/drivers/gpu/drm/gma500/psb_drv.h:41-53](../references/linux/drivers/gpu/drm/gma500/psb_drv.h#L41); [references/linux/drivers/gpu/drm/gma500/psb_device.c:272](../references/linux/drivers/gpu/drm/gma500/psb_device.c#L272); [references/linux/drivers/gpu/drm/gma500/psb_drv.c:261-262](../references/linux/drivers/gpu/drm/gma500/psb_drv.c#L261).

**CONFIRMED:** BRNs of the SGX535 branch: revision 121 active 22934/23944/23410; 126 active 22934; HEAD=0 does not apply BRNs in this block. 23944 affects fault handling before BIF reset; 23410 forces valid TA context. [references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/hwdefs/sgxerrata.h:134-159](../references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/hwdefs/sgxerrata.h#L134); [references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c:173-176](../references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c#L173); [references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c:471-495](../references/omap5-sgx-ddk-linux/eurasia_km/services4/srvkm/devices/sgx/sgxreset.c#L471). **UNKNOWN:** mapping of the Intel stepping for this revision selection.

**INFERRED:** object abstractions, context, CCB, dependencies, and microkernel protocol are useful as a research model. This does not imply ABI, scripts, cache policy, clocks, IRQs, or portable binary firmware. The divergence of BIF indexing in [mmu-bif.md](mmu-bif.md) is a concrete example of the risk.
