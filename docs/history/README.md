# Research archive

[Project history](PROJECT-HISTORY.md) is the short route through the early phases.
The original research files remain at their recorded paths because manifests,
source inventories and later discoveries reference them. Archival organization
here is an index, not a mass rename of evidence.

Use the [current documentation index](../README.md) for reproduction and active
work. Older handoffs and gate reports are dated checkpoints, not current status.
They can contain useful failed hypotheses and instructions that no longer apply.

Raw captures, successful experiment bundles and source snapshots should not be
edited for style or privacy. Keep original hashes and create clearly labeled
sanitized derivatives when publication requires them. Machine-specific launch
scripts inside an archive are historical records, not reusable authorization.
