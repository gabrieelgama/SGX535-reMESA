The `libdrm-poulsbo` source RPM contains a `psb_drm.h` with `PSB_PACKAGE_VERSION "2.2.0.32L.0027"`, PSB driver version 4.21, and no `PSB_DETEAR` tail. Its header SHA-256 is `e53f415c55ad8a9953f2988245e425d941a6410b809891f8372eda937e762f43`. The existing kernel snapshot [header](../../poulsbo-data/PSB_psb_drm_h.txt) instead labels version `5.0.0.0045`, has the optional detear fields and produces the observed 20-byte XHW-init and 144-byte command arguments. `XpsbInit` embeds its own `5.0.1.0046` version string. These are **different version signals**, not an authenticated three-way build manifest. Do not merge their structures by name alone (P7C-007).

Only public source archives were acquired. They remain under `/tmp`, and no recovered restricted binary or source body was added to the repository. The preserved raw ELF bytes remain unchanged.

The [RPM Fusion Fedora 11 source index](https://ftp.gwdg.de/pub/linux/rpmfusion/nonfree/fedora/updates/11/SRPMS/) lists these package families together, including `xpsb-glx-0.18-5`. The retained package's spec is 0.18-4.1. Index co-presence and package dependencies do not authenticate a specific installation or binary build. No second xpsb archive was acquired.
