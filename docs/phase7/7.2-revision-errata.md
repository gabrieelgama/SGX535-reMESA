## Historical encoding, not a value prediction

P7-007: the [SGX535 header](../archaeology-data/H535.txt):89–104 defines `CORE_ID` at `0x0010` with ID bits 31:16 and configuration bits 15:0. At `0x0014`, `CORE_REVISION` has designer bits 31:24, major 23:16, minor 15:8, maintenance 7:0. The historical [PSB read](../poulsbo-data/PSB_psb_drv_c.txt):325–340 decomposes these fields.

No value was supplied to this encoding. It does not prove RO semantics, acceptable power state, or how a future encoded value should map to the decimal DDK revision selectors.
