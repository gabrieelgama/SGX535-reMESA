# Pre-implementation decision after the bounded-path pass

**RESULT B — MINIMAL CLEAN-ROOM 3D USERSPACE PATH NOT YET SPECIFIABLE.** I did not create `docs/phase7/minimal-clean-room-3d-spec.md`: the selected scene branch still has required bytes, state choices and initialization dependencies without a documented value or algorithm. The [bounded program/TA trace](bounded-path-closure.md) and [validation/bootstrap trace](validation-bootstrap-closure.md) are evidence inventories, not code to copy. No driver, hardware experiment or Test Vector One was created.

The later [frozen-draw static decision](frozen-draw-static-decision.md) is the current assessment. It retains Result B while separating unfinished compiler/scene reverse engineering from the PDS consumption question and exact stack-pairing uncertainty. The focused trace now identifies scalar lowering of four primary-color components and the candidate XHW init request fields; neither supplies a complete fragment program or authorizes hardware access.

Letters correspond to the user's source classes: **A** retained `psb_dri.so`, **B** retained `Xpsb.so`, **C** recovered DDX, **D** recovered libdrm, **E** recovered PSB kernel, **F** identifiable companion package/source, **G** unavailable documentation/source, **H** hardware observation. A–F have yielded specific constraints; the remaining A/B/D/E follow-ups above are **not exhausted** and must precede any claim that a particular byte is only obtainable from G/H. Conversely, static analysis cannot by itself validate physical revision, clock/power/reset safety, hardware packet effects, hangs or recovery. G/H are not a reason to execute hardware now.

The historical GL edge is not necessarily a requirement to copy into a modern Mesa frontend. The missing lower-level contract is still required: validated state inputs, program bytes, TA/scene records, BO addresses and synchronization. A clean-room implementation cannot hide these as opaque proprietary payloads. The candidate modern gma500 driver exposes no established historical PSB 3D ioctl ABI. The actual Dell SGX core revision is UNKNOWN; Gate B is **BLOCKED**, CORE_ID/CORE_REVISION are not SAFE-CANDIDATE, whitelist `[]`, and hardware functionality is **UNVERIFIED**.


[P7G frozen draw](frozen-draw-closure.md) supersedes the GL-entry and terminal-padding blockers in this earlier decision. The Result B assessment remains.
