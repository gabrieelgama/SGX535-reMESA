# Frozen triangle: static pre-implementation decision

**RESULT B — MINIMAL CLEAN-ROOM 3D USERSPACE PATH NOT YET SPECIFIABLE.** This decision concerns only the [P7G frozen triangle](frozen-draw-closure.md), not the rest of OpenGL. The historical GL entry, 96-byte position/color vertex input, six index bytes, conditional 16-byte vertex USE output, five-word TA index record, indirect scene finalization and index-0 submission edge remain as previously documented. The 128-byte setup example is eight four-dword records, and finalization commits one terminal word. Neither correction is reopened here.

The new [compiler trace](frozen-fragment-compiler-checkpoint.md) establishes the MOV/END UniFlex input, the selected scalar-lowering branch and the four initial color-component visits. It does **not** establish the selected transformed IR, final instruction count, encoded words or metadata. The [link trace](frozen-fragment-link-checkpoint.md) now gives exact conditional construction rules for the `0x88`-byte link object, but its compiler-derived inputs remain unknown. The new [XHW trace](../xpsb-re/xhw-init-frozen-draw.md) establishes operation zero's consumed fields and the candidate-family scene-info/bind-fire operation mapping. These are genuine reductions, but they do not supply the missing draw bytes. No implementation-grade `minimal-clean-room-3d-spec.md` or Phase 8 plan is justified.

The current source inspection does **not** prove that rank 1 or rank 4 is irreducible: their producing algorithms are in the retained DRI ELF. It proves that the needed outputs have **not yet been derived**. Rank 3 is different: the selected producer leaves bytes unwritten and the available sources have not established whether the PDS reads them. At rank 6, the SGX-derived option is a real-machine-dependent historical input, but its two scene-sizing branches converge for the selected 32×32 target. That removes this input from the frozen draw's scene-size calculation without resolving the Dell's core revision or the rest of XHW bootstrap. Rank 7 is a provenance/compatibility assumption that might be parameterized once every used field is specified. SGX power/clock/reset, first-read side effects and recovery remain outside userspace-format readiness and cannot be waived by this analysis.

No historical ELF was loaded or executed; no ioctl, MMIO, firmware, command, workload or hardware experiment occurred. **Gate B: BLOCKED. CORE_ID/CORE_REVISION: not SAFE-CANDIDATE. Whitelist: `[]`. HARDWARE FUNCTIONALITY: UNVERIFIED.**
