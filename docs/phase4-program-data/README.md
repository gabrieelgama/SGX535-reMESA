# Phase 4 program data

This directory contains manifests, source rechecks, formal-gate data, and validation output for Phases 4.3–4.7. These files record the investigation; they are not primary hardware evidence.

The validator checks CSV/JSON structure, internal links, evidence locators, hashes, gma500 snapshots, gate state, absence of a TV1 implementation, and reference-tree integrity. It performs only local file and Git checks and does not access hardware.
