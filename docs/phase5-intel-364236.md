# Intel document 364236

## Established facts

Intel's public EMGD v1.14 specification update `445348-016US` (April 2012) lists `364236` as *Intel System Controller HUB External Design Specification* on page 6, Table 1 (P5-001). The same table lists the SCH datasheet separately as `319537`, so these are distinct documents.

In a 2021 Intel Community response, an Intel moderator says that `364236` can be accessed after signing into a privileged Resource and Documentation Center account and gives `https://cdrdv2.intel.com/v1/dl/getContent/364236` (P5-002).

On 2026-09-20, an anonymous request to that URL redirected to Intel's public 404 page (P5-005). I did not attempt authenticated access or bypass access controls.

## What remains unknown

The document itself was not obtained. Its revision, classification, table of contents, and technical scope are `UNKNOWN`. Available public metadata does not establish that it covers the SGX aperture, `CORE_ID`, `CORE_REVISION`, register access attributes, power/clock/reset requirements, stepping mappings, errata, CPU MMIO failure behavior, or recovery.

Document `364236` therefore does not close a Phase 5 gate field. An authorized copy would be valuable for review, but only its actual relevant sections could supply evidence.
