# SGX535 rev116 versus rev121

**Physical SGX core revision: UNKNOWN.** No SGX revision was measured on the Dell.

- SGX535 rev116 appears in a 2020 Linux device-tree proposal. This confirms the proposal text, not the silicon in this machine.
- SGX535 rev121 is the default target in a historical Poulsbo DDK build. This confirms a software build target, not the manufactured core.
- rev121/rev126 selectors and other SGX535 revision constants in historical headers are software configuration.
- SGX_CORE_REV strings generated by historical software do not identify the chip.

No available source establishes that the Dell contains rev116, rev121, or another SGX535 revision.
