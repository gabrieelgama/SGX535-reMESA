# Internal working notes

AI-only prompts and session-continuation notes belong in `ai-handoffs/`, which
Git ignores. Research, evidence, checkpoints, audits, procedures, reproducibility
records, source and tests remain public.

A name containing ChatGPT or Codex does not make a file disposable. Historical
handoffs referenced by evidence hashes, snapshots, scripts or scoped diffs stay
at their recorded paths. See the [publication audit](../docs/publication-audit.md)
for the reviewed files and retained evidence.
